## 7 ноября 2026 — каталог просмотра и обновлённый поиск

Эта запись отделена от результатов 6 ноября: старые числа источников, состав выдачи и скриншоты выше относятся к предыдущему интерфейсу.

### Изменения реализации

- Главная, топ, карточки и общий поиск отфильтровывают записи без `playable`. AniList, Shikimori и Kitsu остаются справочными источниками с `playback: false`; отдельные карточки без видео не показываются как доступные к просмотру. Сам флаг `playable` не заменяет проверку потока выбранной серии.
- В интерфейсе каталога добавлен выбор Kodik / AniLibria.TV. Переходы между страницами учитывают курсоры провайдера; параметры фильтров остаются в URL.
- Курсоры Kodik хранятся на сервере один час, привязаны к фильтрам и не раскрывают токен API. Просроченный курсор возвращает 410; интерфейс предлагает открыть первую страницу. Повторяющийся курсор источника не создаёт бесконечные пустые страницы.
- Поиск альтернативных названий дополняет выдачу Kodik по подтверждённому Shikimori ID. Регрессионный сценарий «Резе» использует ID `57555`; старые справочные карточки разрешаются в видеоверсию только при подтверждённой связи ID. Несовпадающие MAL ID отклоняются.
- AnimeVost распознаёт запись «Фильм» как серию 1, проверяет плейлист и скрывает пустые записи или трейлеры без эпизодов. Постеры с устаревшего `static.openni.ru/uploads/posts/` переводятся на соответствующий HTTPS-путь основного сайта AnimeVost.
- Полный поиск выполняет запрос после 300 мс без ввода, отменяет предыдущие запросы и отклоняет устаревшие ответы. Карточки и таблица используют одну выдачу. Сортировка доступна по совпадению, названию, году, рейтингу, числу серий и источнику; неизвестные числа не подменяются нулями в отображении.
- Быстрый поиск в шапке использует выпадающую выдачу с постерами и клавиатурную навигацию. Открытие полного поиска сохраняет запрос.
- Выбор сезона и серии перенесён над видео. Список всех серий раскрывается отдельно, сохраняется поиск по номеру.
- Выбор языка и типа перевода оформлен отдельными кнопками. При отсутствии сохранённого языка или типа показываются доступные варианты, выбранная студия запоминается.
- Устаревшая ссылка на поток вызывает однократное обновление источника; другие ошибки позволяют попробовать альтернативный формат той же озвучки. Сохраняется ручная повторная попытка. Это поведение не означает доступность всех форматов у каждого провайдера.
- Ползунок громкости изменяет `video.volume` непосредственно при вводе; mute сохраняет последний ненулевой уровень. Мобильная панель содержит ползунок и кнопки ±5%, клавиши ↑/↓ меняют громкость. Описание подтверждено кодом; результаты интерактивной проверки фиксируются отдельно ниже.
- Используется предоставленный пользователем логотип `frontend/public/brand/delta-eye.png`; обновлены карточки и страница аниме.

### Источники и границы проверки

Повторное исследование трёх репозиториев и живые запросы к Shikimori, Kitsu, Jikan и Senshi зафиксированы в [docs/SOURCES.md](docs/SOURCES.md). Непроверенные или недоступные видеоадаптеры не объявляются рабочими источниками просмотра. Число результатов и наличие озвучек зависят от ответа конкретного провайдера.

Фильтр доступности проверяет наличие подходящих ссылок и эпизодов в ответе источника, а для AnimeVost — содержимое плейлиста. Он не выполняет проверку каждого медиапотока: карточка или список студий не гарантирует воспроизведение всех серий, озвучек и качеств. Произвольные названия и будущие релизы не объявляются доступными только по метаданным.

Команды для итоговой проверки этой версии:

```sh
.venv/bin/python -m pytest -q
node --test tests/*.test.mjs
npm run build
docker compose up -d --build --wait --wait-timeout 120
.venv/bin/python scripts/smoke.py http://127.0.0.1:8080
```
