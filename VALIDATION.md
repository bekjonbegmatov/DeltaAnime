# Проверка DeltaAnime — 6 ноября 2026

- `npm run build`: успешно, TypeScript и production build. hls.js загружается отдельным chunk; Vite предупреждает о его размере.
- `.venv/bin/python -m pytest -q`: 30 тестов пройдено. Есть предупреждение Starlette о будущем переходе TestClient с httpx на httpx2.
- Тесты покрывают ошибки частичных результатов, идентичность релизов, исключение другого сезона, ручное подтверждение без ID, сохранение SQLite, фильтры каталога, sparse episode numbering, недоступный эпизод, закрытый релиз, relay handles, приватные адреса, HLS URI и полное отключение удалённого источника.

## Живые запросы

- AniLiberty: каталог 1884, фильтрация года/типа/статуса/жанра и пагинация. Bleach HLS первых двух серий и медиасегменты отвечают 200.
- AniList: топ 24 карточки и поиск.
- Animedia: Bleach 366 серий; несколько плееров, извлечение потока.
- Alloha: Bleach 2 сезона (366/48), 4 перевода на тестовой серии; iframe открыт в браузере, смена озвучки и переход к следующей серии проверены.
- AnimeVost: поиск Blue Lock, 24 серии; MP4 720p через relay ответил 206, сигнатура `ftypisom` подтверждена. Проверены серии 1 и 7 на стороне API.
- AnimeLib: поиск Bleach, описание, 366 серий, 6 переводов на серии 1. Для AniDUB и AniLibria.TV получено по 6 вариантов потоков; HLS AniDUB через relay вернул 200 и `#EXTM3U`.
- Сопоставление AniLiberty `lib-8452` → AnimeLib `aml-246` подтверждено по общему MAL ID.
- AnimeGO: поиск не отвечает корректно; ошибка не мешает остальным источникам.
- Kodik: общий stable-токен AnimeParsers принят API, поиск работает. Blue Lock (Shikimori 49596): 24 серии и 19 переводов на серии 7; AniDUB — 6 потоков, HLS через relay 200. Токен не выводился в лог и не передаётся браузеру.
- AniLibria.TV: прямой HLS 480/720/1080, HTTP 200; браузер подтвердил воспроизведение второй серии Bleach после перехода «Следующая серия».
- Anime365 отключён по запросу пользователя. Проверки гарантируют отсутствие в реестре, отклонение поиска и старых страниц.

## Интерфейс кинотеатра

- Новая главная: настоящие баннеры AniList, горизонтальные ленты релизов, рейтинга, онгоингов и фильмов, компактное продолжение просмотра.
- Каталог: в браузере выбран формат «Фильм», URL получил `kind=MOVIE`, API вернул 149 тайтлов с постерами.
- Поиск Blue Lock: 15 объединённых результатов, 7 из 8 источников ответили; ошибка AnimeGO показана отдельно. Фильтры 2022 + «С источником просмотра» оставили 3 результата и сохранились в URL. Переход к карточке Kodik и продолжению серии 7 работает.
- Детальная страница: постер, информация, локализованные формат/статус/жанры, продолжение с позиции, закладки и поиск других озвучек.
- Плеер: Big Buck Bunny воспроизводится через HLS; пауза, скорость 1.5×, сохранение настроек после reload проверены в браузере.
- Реальный Blue Lock, серия 7, AniLibria.TV через Kodik: opening 38–133, ending 1286–1440 при продолжительности 1430.6. Включённый автопропуск после перехода к 40 секунде перемотал за 133. Автоматическое завершение серии 7 перевело на серию 8, она воспроизводилась с той же озвучкой.
- После UI-проверок тестовые настройки восстановлены. Режим кинотеатра сохраняет доступ к озвучкам под видео.
- Fullscreen запрашивается из пользовательского Play. Встроенный IAB не подтвердил переход в fullscreen; код сообщает ограничение и предлагает режим кинотеатра. Работу fullscreen в обычном браузере ещё нужно подтвердить отдельно.
- `node --test tests/player-settings.test.mjs`: 5 тестов нормализации настроек, таймкодов, отдельных переключателей opening/ending, выбора качества и времени. Проверяется сохранение сцен после эндинга и отсутствие выдуманных таймкодов.
- Проверка 390×844: поиск и карточка без горизонтального переполнения (scrollWidth = clientWidth = 390), мобильная панель настроек плеера доступна и прокручивается. Устранено переполнение от фонового изображения карточки. Обычный размер браузера после проверки восстановлен.
- Снимки обновлённого интерфейса: `docs/cinema-home.jpg`, `docs/cinema-search.jpg`, `docs/cinema-detail.jpg`, `docs/cinema-player.jpg`, `docs/cinema-player-mobile.jpg`, `docs/cinema-search-mobile.jpg`.

Не все студии доступны на каждой серии. Названия из API не считаются доказательством работоспособности каждого видео. Публичный запуск сервиса требует отдельной подготовки доступа и relay; публикация исходного кода не означает открытый видеосервис.


## Docker и доставка

- Многоэтапная сборка Node 22 → Python 3.13 успешно собрана для Linux arm64 на Docker Desktop. Зависимости установлены внутри Linux, локальная `.venv` не используется.
- `docker compose up -d --wait` завершился со статусом healthy. Интерфейс и API доступны на одном порту 8080.
- `scripts/smoke.py`: health, корень, `/catalog`, `/search`, страницы аниме/просмотра, JS assets и cache headers прошли. Неизвестные API/файлы возвращают 404, посторонний Host — 400. Внешние провайдеры не нужны для smoke test.
- Runtime: UID 10001, файловая система только для чтения; `/data` — постоянный том, `/tmp` — tmpfs. Локальные база и env-файлы в образ не попали.
- После пересоздания контейнера тестовая запись SQLite сохранилась; запись после проверки удалена.
- Локально: 30 Python-тестов, 5 проверок плеера, production build успешно.
- GitHub Actions проверяет тесты/frontend и сборку+HTTP smoke на Linux amd64. Статус последнего запуска доступен по badge в README.
