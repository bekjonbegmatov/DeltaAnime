# Источники DeltaAnime — исследование 6 ноября 2026

Реестр не является обещанием охватить весь интернет. Отдельно учитываются каталог, поиск, список переводов, извлечение видео и фактическое воспроизведение. Наличие репозитория или ответ HTTP 200 не доказывают работоспособность видео.

## Подключены

| Источник | Возможности | Проверено / ограничение |
|---|---|---|
| AniLibria.TV (API AniLiberty) | Каталог, фильтры, русские описания, постеры, поиск, серии, HLS | 1884 релиза на момент проверки; HLS и сегменты загружаются |
| AniList | Топ, поиск, сведения, связи аниме, MAL ID | Реальные ответы; видеопотоков нет |
| AnimeLib | Поиск, описания, серии, команды перевода, Kodik, собственные MP4 | «Блич»: 366 серий, 6 вариантов на серии 1; извлечены потоки AniDUB и AniLibria.TV; HLS AniDUB отвечает 200 |
| AnimeVost | Поиск, описания, постеры, серии, MP4 480/720 | «Блю Лок»: 24 серии; MP4 отвечает 206 и содержит сигнатуру ISO MP4 |
| Animedia | Поиск, страницы, серии, собственный плеер и Kodik | «Блич»: 366 серий; извлечение потока работает |
| Alloha | Одно совпадение, сезоны, серии, озвучки, iframe | «Блич»: 2 сезона, 4 перевода на тестовой серии. iframe загружается; управление его прогрессом недоступно |
| AnimeGO | Поиск и связанные плееры через anime-dl-core | При проверках поиска HTTP 500; сбой показан отдельно |
| Kodik API | Поиск, серии, переводы | Подключён общий токен AnimeParsers. Blue Lock: 24 серии; 19 переводов на серии 7; HLS AniDUB проверен. Собственный KODIK_TOKEN имеет приоритет |

Восемь источников участвуют в поиске без пользовательского ключа, включая AnimeGO с текущей ошибкой. Kodik использует автоматически найденный опубликованный общий токен. Это число адаптеров, а не гарантия доступности каждого источника.

Anime365 исследован, но **полностью отключён по запросу пользователя**: нет поиска, адаптера, озвучек или сетевых запросов к нему. Старые URL отклоняются, страница Blue Lock перенаправляется на AnimeVost.

## Сопоставление и просмотр

- Общий MAL/Shikimori ID позволяет автоматически добавить версии одного релиза в просмотр. Конфликт ID исключает совпадение.
- При отсутствии ID найденные версии требуют выбора пользователя. Название само по себе недостаточно: фильмы, второй сезон и первый сезон нельзя объединять автоматически.
- Подтверждённые версии сохраняются локально. Список доступных серий объединяется, озвучки добавляются независимо по мере ответов источников.
- Студия перевода и видеоплеер разделены. Одинаковая студия может иметь несколько плееров. Есть язык, озвучка/субтитры и поиск студии.
- Нативные внешние ASS-субтитры AnimeLib пока не отображаются: такие варианты не выдаются за готовый просмотр с субтитрами.
- Автопереход и сохранение позиции работают для нативного HLS/MP4. Для iframe доступны ручные переходы между сериями.

## Найденные дополнительные направления

В `backend/source_inventory.json` и на `/sources` сохранены ещё 15 сервисов/проектов: Anixart, YummyAnime, сайты AniDUB и AniStar, AnimeBuff, AnimePahe, AnimeFLV, Crunchyroll, Kitsu, AniDB, Anime News Network, SIMKL, Anilote, Consumet, Aniyomi extensions. Они не обозначены работающими адаптерами. У каждого указан текущий пробел проверки или интеграции.

Дополнительно: JutSu — парсер без подключённого общего поиска; Shikimori и Jikan — прямой API недоступен из этой сети. Извлекатели Aniboom, CVH, Kodik, Sibnet, Animedia, AniLibria и VK доступны через anime-dl-core; SovetRomantica отмечен недоступным. Извлекатель по ссылке не равен отдельному поисковому каталогу.

## Проверенные исходники и ссылки

- [anime-dl-core](https://github.com/ialakey/anime-dl-core) — используется как Python-зависимость.
- [AnimeParsers](https://github.com/YaNesyTortiK/AnimeParsers) — изучены API и возможности парсеров; не запускается как второй дублирующий backend.
- [Aniyomi: русские адаптеры](https://github.com/fallen02/aniyomi-sources/tree/main/src/ru) — изучены протоколы AnimeLib/AnimeVost. Kotlin-код не копировался в приложение; написаны самостоятельные Python-адаптеры по ответам публичных API.
- [AnimeVost API proxy](https://github.com/ReanSn0w/avproxy) — справочник API; прокси не развёртывался, запросы идут непосредственно к api.animevost.org.
- [Anixart](https://github.com/SantaSpeen/anixart) — найден клиент с авторизацией; не подключён.
- [awesome-anime-sources](https://github.com/anshumanv/awesome-anime-sources) — обзор кандидатов, не свидетельство их текущей доступности.
- [Consumet](https://github.com/consumet/consumet.ts) — GitHub API при проверке вернул 451 Repository access blocked; не установлен.
- [Anilote API](https://anilote.me/api) — документация найдена, тестовый запрос завершился таймаутом.
- [AniLiberty API](https://anilibria.top/api/docs/v1), [AniList API](https://docs.anilist.co/) — каталоги и метаданные.

Чтобы расширять покрытие дальше: подключать кандидатов по одному, проверяя поиск → точное совпадение релиза → серии → перевод → реальную загрузку потока. Сначала полезнее расширять работающие агрегаторы, чем добавлять десятки непроверенных доменов.

## Автоматический токен Kodik

Реализовано по [KODIK_API.md](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/KODIK_API.md#как-получить-api-ключ) и [TOKENS.md](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/kdk_tokns/TOKENS.md). Читаются только опубликованные stable/unstable кандидаты, максимум три; legacy/dead не используются. TLS-проверка включена. Токен проверяется реальным запросом, хранится в памяти шесть часов; неудачная попытка получения кешируется на десять минут. Код из репозитория не исполняется. Установленный KODIK_TOKEN всегда имеет приоритет, автоматический режим можно отключить KODIK_AUTO_TOKEN=0. Доступность общего токена может измениться.

Карточки Kodik объединены по Shikimori ID, сохраняя все найденные переводы в плеере. При подборе к уже известному MAL/Shikimori ID используется поиск по ID, а не название. Запросы ограничены 100 записями upstream.
