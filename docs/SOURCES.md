# Источники DeltaAnime — исследование 7 ноября 2026

Реестр не является обещанием охватить весь интернет. Отдельно учитываются каталог, поиск, список переводов, извлечение видео и фактическое воспроизведение. Наличие репозитория или ответ HTTP 200 не доказывают работоспособность видео.

На сервере подключены десять поисковых адаптеров без пользовательского ключа: семь источников просмотра и три каталога метаданных. Пользовательская выдача теперь показывает только версии для просмотра; метаданные используются для поиска названий, обложек и подтверждения идентификаторов. AnimeGO сохраняет отдельный адаптер с последней известной ошибкой; актуальный ответ проверяется при поиске. Kodik использует автоматически найденный опубликованный общий токен. Это число адаптеров, а не гарантия доступности каждого источника.

Anime365 исследован, но **полностью отключён по запросу пользователя**: нет поиска, адаптера, озвучек или сетевых запросов к нему. Старые URL отклоняются, страница Blue Lock перенаправляется на AnimeVost.

## Сопоставление и просмотр

- Общий MAL ID или общий Shikimori ID позволяет автоматически добавить версии одного релиза в просмотр. Эти пространства идентификаторов сравниваются отдельно: MAL 125 не равен Shikimori 125. Конфликт любого общего ID исключает совпадение.
- При отсутствии ID найденные версии требуют выбора пользователя. Название само по себе недостаточно: фильмы, второй сезон и первый сезон нельзя объединять автоматически.
- Подтверждённые версии сохраняются локально. Список доступных серий объединяется, озвучки добавляются независимо по мере ответов источников.
- Студия перевода и видеоплеер разделены. Одинаковая студия может иметь несколько плееров. Есть язык, озвучка/субтитры и поиск студии.
- Нативные внешние ASS-субтитры AnimeLib пока не отображаются: такие варианты не выдаются за готовый просмотр с субтитрами.
- Автопереход и сохранение позиции работают для нативного HLS/MP4. Для iframe доступны ручные переходы между сериями.

## Автоматический токен Kodik

Реализовано по [KODIK_API.md](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/KODIK_API.md#как-получить-api-ключ) и [TOKENS.md](https://github.com/YaNesyTortiK/AnimeParsers/blob/main/kdk_tokns/TOKENS.md). Читаются только опубликованные stable/unstable кандидаты, максимум три; legacy/dead не используются. TLS-проверка включена. Токен проверяется реальным запросом, хранится в памяти шесть часов; неудачная попытка получения кешируется на десять минут. Код из репозитория не исполняется. Установленный KODIK_TOKEN всегда имеет приоритет, автоматический режим можно отключить KODIK_AUTO_TOKEN=0. Доступность общего токена может измениться.

Карточки Kodik объединены по Shikimori ID, сохраняя все найденные переводы в плеере. При наличии явного Shikimori ID Kodik ищется по этому ID. Один MAL ID не подставляется вместо Shikimori: в таком случае используется поиск названия, а неподтверждённые версии требуют ручного выбора. Kodik и AnimeLib больше не выводят MAL ID из числа Shikimori; старые сохранённые карточки Kodik очищают такое предположение при открытии. Запросы ограничены 100 записями upstream.

## Контракт новых каталогов

`shikimori` и `kitsu` имеют `search: true`, `playback: false`, `type: Метаданные`. Карточки `shiki-*` / `kitsu-*` открываются напрямую, без предварительного поиска. Видео, озвучки и наличие доступных серий эти источники не обещают. Поиск и карточки используют таймауты, кеш пять минут и общую обработку частичного сбоя; ошибка одного каталога не удаляет результаты остальных.

- [Shikimori REST API](https://shikimori.io/api/doc/1.0/animes/index): запросы `/api/animes` и `/api/animes/:id`. Проверен русский поиск и описание Blue Lock, жанры «Сёнен», «Спорт», студия 8bit. HTML описания преобразуется в текст, сохраняются абзацы. Поиск возвращает Shikimori ID; MAL ID берётся только из явного поля `myanimelist_id` карточки. Числовое равенство IDs не предполагается. Некешированные запросы ограничены интервалом 0,8 с.
- [Kitsu API](https://kitsu.docs.apiary.io/): проверены `/api/edge/anime` и `/api/edge/anime/:id` с `Accept: application/vnd.api+json` и `include=mappings,categories`. У текущих ответов `genres` пустой; используются категории. Связи MAL берутся только из mappings, принадлежащих конкретной карточке через JSON:API relationships, и только из пространства `myanimelist/anime`. Чужая mapping, Manga ID, отсутствующий или конфликтующий MAL не используются для объединения.
- [Jikan API](https://api.jikan.moe/v4/anime?q=Blue%20Lock&limit=2&sfw=true): повторный запрос завершился таймаутом; проверка TLS не отключалась. Jikan остаётся отключённым.

Новые адаптеры покрыты тестами: разделение сезонов Kitsu, конфликтующие/непринадлежащие карточке mappings, явный MAL ID Shikimori, очистка HTML, metadata-only контракт, прямые страницы, обязательный заголовок Kitsu, кеширование и частичный отказ.


Из видеоадаптеров Kitsune отдельно проверен [Senshi](https://github.com/Dovakiin0/Kitsune/blob/master/src/lib/providers/providers/senshi.js): его прямые запросы `https://senshi.to/episodes/49596` и `https://senshi.to/episode-embeds/49596/1` оба вернули **HTTP 523** 07.11.2026. Поиск потока не продолжался, источник не подключён. [Ani.pm](https://github.com/Dovakiin0/Kitsune/blob/master/src/lib/providers/providers/anipm.js) и [AnimeOnsen](https://github.com/Dovakiin0/Kitsune/blob/master/src/lib/providers/providers/animeonsen.js) изучены на уровне исходников: первый использует отдельный wreq-транспорт и цепочку Settlar-сессий, второй — начальную сессию и динамические API/search origins. Их воспроизведение не проверено.


## Каталог для просмотра и фильм «История Резе» — обновление 7 ноября

Основной `/api/catalog` теперь использует реальный пагинированный `/list` Kodik вместо ограниченного каталога одной команды озвучки. По `/api/top` возвращаются доступные видео из этого же каталога с сортировкой по оценке Shikimori. Поддерживаются фильтры жанра, года, формата и статуса, сортировка по обновлению/рейтингу/году. В параметре `provider=aniliberty` сохранён отдельный каталог AniLibria.TV.

Kodik `/list` возвращает записи переводов: например, при проверке свежей выдачи сервер сообщил 33 829 записей, а не столько уникальных аниме. Поэтому этот счётчик не показывается как число тайтлов. На каждой странице до 24 уникальных релизов; проверены первые две страницы свежей выдачи и топа — по 24, без повторов между страницами. Работа ограничена четырьмя upstream-страницами за запрос, остаток выдачи сохраняется. Курсоры случайные, серверные, действуют час и связаны с фильтрами. URL и API-токен Kodik никогда не возвращаются клиенту; повторяющийся upstream-курсор прекращает пагинацию. При сбое первой страницы Kodik доступен явно обозначенный резерв AniLibria; курсоры разных каталогов не смешиваются.

Наличие просмотра проверяется по ответу источника: у фильма должна быть ссылка плеера, у сериала — положительное число эпизодов и ссылки сезонов/эпизодов. Неаниме, анонсы, записи без плеера и пустые сериалы исключаются. AniLibria проверяется пакетным `/anime/releases/list`: нужны реальные HLS-ссылки эпизодов и отсутствие блокировки. Общий счётчик AniLibria тоже не выдаётся за число проверенных доступных релизов. Это проверка наличия видео у API, а не обещание доступности каждого CDN в любой сети.

**Chainsaw Man Movie: Reze-hen** подтверждён как Shikimori 57555 и Kodik `kd-shiki-57555`. Найдено 15 переводов; проверено извлечение потока AnimeVost через Kodik — варианты 360/480/720p. Фильм содержит один эпизод; отсутствие `episodes_count` у фильма не считается отсутствием видео. Прямой поиск Kodik по короткому «Резе» возвращал ноль, поэтому добавлен поиск подходящего названия в Shikimori с последующим запросом по его явному ID. Нерелевантные совпадения по описанию в Shikimori не используются для такого расширения.

Старые информационные страницы могут запросить `/api/titles/{id}/watchable`. Если известен только MAL, сначала находится кандидат Shikimori и проверяется его явный `myanimelist_id`; равенство чисел в разных пространствах не предполагается. Только затем запрашивается Kodik. Конфликт подтверждённых ID исключает версию. Постер, обложка и описание исходной карточки дополняют найденное видео, если соответствующие поля пусты.

Дополнительные тесты покрывают фильмы без `episodes_count`, пустые сериалы, реальные ссылки эпизодов, дедупликацию переводов на соседних страницах, курсоры без токенов, истечение/смену фильтров, циклическую пагинацию, фильтры каталога, подтверждение MAL → Shikimori, конфликт ID, релевантность поиска и пакетную доступность AniLibria.
